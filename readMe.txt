------------------------------------TomTroc--------------------------------------------

Pour installer le projet téléchargez le depuis le repository

pour le clone avec Git :
https://github.com/tmagnum51-spec/P4-exercice1.git

lien vers le zip :
https://github.com/tmagnum51-spec/P4-exercice1/archive/refs/heads/main.zip.

Le dossier P4-exercice1 doit etre placé dans le dossier htdocs de votre server (xampp).

Importez la base de donnée grace au fichier tomtroc.sql à la racine.

lien vers l'index :
http://localhost/P4-exercice1/index.php

Des images de test ont été laissées à disposition pour la creation de livres ou de comptes.

Le mot de passe de tous les comptes déjà présents est "toto"
